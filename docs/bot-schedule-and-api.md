# Боты Corefy и Cardaq: расписание, даты и API

## Расписание (Laravel scheduler, нужен `schedule:run` в cron)

| Бот                          | Когда стучится                                                                                                | Какой отчёт берёт             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| **Corefy** (`corefy-export`) | раз в день утром: каждый час с 06:00 до 12:00 (по `STERLING_REPORT_TIMEZONE`), пока отчёт за вчера не получен | T+1: сегодня 20-е, берёт 19-е |
| **Cardaq** (`cardaq-export`) | **каждый час**, круглые сутки: ищет письмо с отчётом                                                          | T+2, см. ниже                 |

Бот берёт не «сегодня минус N дней», а **долги по отчётам** (`PendingReportFinder`): какие периоды уже должны быть у провайдера, но файла ещё нет. Получили файл — период закрывается и бот больше за ним не идёт.

## Какие даты ждёт Cardaq (задержка 2 дня)

- Среда → отчёт готов в пятницу (T+2).
- Выходные склеиваются: пятница + суббота + воскресенье дают **один** отчёт с датой воскресенья, он ждётся в **понедельник**.
- Понедельник → отчёт в среду, и так далее. Праздничные дни склеиваются так же.
- Письма может ещё не быть: тогда запуск завершается как `skipped`, и бот пробует через час.

Задержка провайдера (`report_delay_days`: Cardaq 2, Corefy 1) задаётся в Providers.

## Почтовый ящик Cardaq (Hostinger / PrivateEmail)

В Admin → Bots у аккаунта Cardaq поле **Mailbox**: Hostinger или PrivateEmail. На каждый ящик свой аккаунт со своим логином и паролем. Название компании для поиска письма: настройка `search_query` (например `WORKING AGENT LTD`).

## API для внешнего бота (старый Node-бот)

Заголовок `Authorization: Bearer {BOT_REPORTS_API_KEY}` на всех запросах.

| Запрос                                                             | Для чего                                                                                                         |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `GET /api/v1/reports/pending-tasks?provider=corefy` (или `cardaq`) | какие даты ещё нужны по каждому MID: `companies[].pending_reports[]` с `report_date`, `from`, `to`, `date_range` |
| `POST /api/v1/reports/upload/{corefy\|cardaq\|madfin\|…}`          | файл отчёта: `merchant_id` (id нашего MID из `merchant_wallet_id`), `report_date`, `file`                        |
| `POST /api/v1/transactions/import`                                 | старый маршрут для CSV Cardaq (то же, что upload/cardaq)                                                         |
| `POST /api/v1/reports/upload/chargeback`                           | файлы чарджбэков Cardaq. Принимается и сохраняется, **к отчётам пока не применяется**                            |
| `POST /api/v1/transfers/lapkipay`                                  | пакет C2B-транзакций LapkiPay (см. `lapkipay-api.md`)                                                            |

Встроенные боты (запуск из Laravel) этим API не пользуются: они сами берут долги и загружают файлы.
